# 📊 Social Media Campaign Performance Tracker
**Internship Track:** Data Science & Analytics (DS)  
**Task Number:** 02  
**Organization:** Future Interns  

---

## 📌 Project Overview
This project focuses on analyzing **social media advertising campaign data** (Facebook / Instagram) to evaluate campaign effectiveness.  
The analysis measures key marketing metrics such as **engagement, CTR, CPC, conversions, and ROI**, and presents insights through a clean, interactive dashboard.

The goal is to help marketers understand campaign performance and optimize future ad strategies.

---

## 🎯 Objectives
- Analyze campaign performance across platforms
- Measure engagement, CTR, CPC, and ROI
- Identify top-performing and underperforming campaigns
- Provide actionable insights for campaign optimization

---

## 🧰 Tools & Technologies
- **Power BI / Google Looker Studio**
- **Microsoft Excel / Google Sheets**
- **Canva** (optional – for presentation visuals)

---

## 📂 Dataset
The dataset contains advertising campaign data including:
- Campaign Name
- Platform (Facebook / Instagram)
- Impressions
- Clicks
- Engagement
- Spend
- Conversions
- Revenue

> *Note: Dataset used may be original or sourced externally as per internship guidelines.*

---

## 📈 Key Metrics Analyzed
- Impressions
- Click-Through Rate (CTR)
- Engagement Rate
- Cost Per Click (CPC)
- Conversion Rate
- Return on Investment (ROI)

---

## 📊 Dashboard Features
- Platform-wise performance comparison
- Campaign-level KPI cards
- Spend vs Revenue analysis
- CTR and Engagement
